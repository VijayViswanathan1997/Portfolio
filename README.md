# Portfolio

A personal portfolio site — warm ivory and deep indigo, with a periodic-table
skills grid, a draggable lanyard ID badge, and a horizontal project accordion.

```bash
npm run dev     # http://localhost:3000
npm run build
```

**Edit `lib/content.ts`** — every piece of text, every skill, project and link
on the site comes from that one file.

See **[SETUP.md](./SETUP.md)** for filling in your details, producing the hero
figure, and deploying.
